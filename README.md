# 🌦️ Weather Forecast App

A responsive and user-friendly weather forecasting app built with React. It fetches real-time weather data using the OpenWeatherMap API and allows users to view current weather conditions for any city.

## 🚀 Features

- 🌍 Search weather by city
- 📦 Uses OpenWeatherMap API
- 🔁 React Router for multiple pages:
  - Home
  - About
  - Services
  - Contact
  - 404 Not Found page
- 💅 Styled with custom CSS

## 🔧 Tech Stack

- React
- Axios
- React Router DOM
- OpenWeatherMap API
